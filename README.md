# landing-page-doctor

Landing page statique pour le cabinet du **Dr Moussa Ezzahraoui**.

## Contenu

- `index.html` : page principale
- `assets/style.css` : style
- `assets/app.js` : logique embed reservation
- `assets/doctor-cabinet.webp` : photo cabinet

## Booking embed

Par defaut, la page charge:

`http://cabinet-dr-moussa-ezzahraoui-3041ea.localtest.me`

Pour changer dynamiquement, utilisez:

`?bookingUrl=https://votre-domaine-booking.com`

Exemple:

`https://youssefamimi10.github.io/landing-page-doctor/?bookingUrl=https://demo.sirwaji.com`
